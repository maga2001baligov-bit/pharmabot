# Фармаколог-бот (тренажёр тестов и рецептов)

Что умеет:
- **Тесты — тренировка**: все 159 заданий вразброс, без ограничений по времени. Часть (63 шт.) — с интерактивными вариантами ответа (тапнул — сразу видно, верно или нет). Остальные (соответствия/таблицы/вставить слово) — в формате карточки: сначала пробуешь вспомнить сам, потом жмёшь «Показать ответ».
- **Тесты — экзамен**: билет из 40 случайных заданий (как на настоящем экзамене, где 35–45), в конце — итоговый счёт.
- **Рецепты — тренировка**: показывает препарат, ты вспоминаешь Rp., потом сверяешь и отмечаешь «знал / не знал».
- **Рецепты — экзамен**: билет из 20 случайных рецептов.
- **Статистика**: сколько заданий разобрано, точность по тестам и рецептам. Хранится в SQLite (`progress.db`), отдельно для каждого пользователя (по Telegram ID) — можно пользоваться вдвоём/втроём одним ботом, у каждого свой прогресс.

## 1. Получить токен бота

1. В Telegram открой **@BotFather**.
2. Команда `/newbot`, придумай имя и username (должен заканчиваться на `bot`).
3. BotFather пришлёт токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` — сохрани его.

## 2. Запуск локально (проверить, что всё работает)

```bash
cd pharmabot
pip install -r requirements.txt
export BOT_TOKEN="твой_токен_от_botfather"
python bot.py
```

Дальше просто открой своего бота в Telegram и напиши `/start`.

## 3. Деплой, чтобы бот работал 24/7 (Railway — самый простой вариант)

1. Зарегистрируйся на [railway.app](https://railway.app) (можно через GitHub).
2. Залей папку `pharmabot` в GitHub-репозиторий (или воспользуйся Railway CLI / drag-and-drop деплоем — в интерфейсе Railway есть загрузка проекта без Git).
3. В Railway: **New Project → Deploy from GitHub repo** → выбери репозиторий.
4. В настройках проекта (Variables) добавь переменную `BOT_TOKEN` со своим токеном.
5. Railway сам определит `requirements.txt` и запустит `python bot.py` (если не запустится автоматически — в Settings → Start Command укажи `python bot.py`).
6. Готово — бот работает постоянно, полить (long polling) не требует открытого порта.

**Важно про статистику:** файл `progress.db` живёт на диске контейнера. При обычном редеплое Railway он может слететь. Если хочешь, чтобы статистика не терялась — в Railway добавь **Volume** (Settings → Volumes) и примонтируй его, например, в `/data`, а потом укажи переменную окружения так, чтобы `DB_PATH` указывал туда (можно попросить меня доработать код под это, когда дойдём до этого шага).

### Альтернативы Railway
- **Render.com** — тоже просто, но на бесплатном тарифе "Background Worker" может засыпать/иметь ограничения; веб-сервисы там требуют открытый порт (нашему боту это не нужно, поэтому выбирай именно Worker/Background Service, не Web Service).
- Обычный **VPS** (например, Timeweb, любой недорогой) — просто держишь процесс через `systemd` или `tmux`/`screen`. Надёжнее всего, но нужно чуть больше возни с настройкой сервера.

## 4. Структура файлов

```
pharmabot/
├── bot.py            # вся логика бота
├── requirements.txt
├── data/
│   ├── tests.json     # 159 тестовых заданий
│   └── recipes.json   # 143 рецепта
└── progress.db         # создаётся автоматически при первом запуске
```
